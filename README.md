## Overview

TX16Wx is a full-featured software sampler with multi-sample mapping, velocity zones, round-robin groups, built-in effects, and Lua scripting for complex instrument programming.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **TX16Wx** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multi-Sample Mapping** | Drag-and-drop velocity, note, and round-robin group assignment |
| **Effect Chain** | Per-program insert effects including reverb, chorus, and EQ |
| **Lua Scripting** | Program complex instrument behavior using embedded Lua scripts |
| **SFZ Support** | Import SFZ format instrument definitions with full parameter mapping |
